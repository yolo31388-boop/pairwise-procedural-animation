# 游戏内程序化动画生成与动作系统

## 项目描述

游戏内程序化动画生成与动作系统的bug修复项目。核心模块 `animation/procedural.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 动画生成完全没做动画都是预录的
- 动作合成完全没做不能混合多个动作
- 运动学完全没做不能计算关节运动
- 动画混合完全没做动作切换是瞬间的
- 程序化行走完全没做角色走路像机器人

## 运行测试

```bash
python -m pytest tests/test_procedural_animation.py -q
```

修复目标：所有 16 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
